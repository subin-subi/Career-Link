# CareerLink
A LinkedIn-inspired professional networking platform built using React.



## Description
CareerLink is a professional networking web application where users can:
- Create an account
- Login securely
- Build a professional profile
- Connect with others
- Explore career opportunities

This project is built as part of my MERN stack learning journey.






## Tech Stack
- React
- React Router
- Tailwind CSS
- JavaScript (ES6)
- Vite
